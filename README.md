## 3. 代打材料与五金配件建议

- **最推荐材料**：**`PETG-CF`（碳纤增强，弯曲刚度提升 `+65%`、耐温 `~85°C`、消光深空灰磨砂质感）** 或 **`PETG` 哑光工程料**（耐温 `~75°C`）。*严禁使用普通 PLA（耐温仅 55°C 且长期静载易蠕变下凹）。*
- **五金配件（淘宝合计约 ¥20–30）**：
  1. `1/4"-20 × 14mm` 相机快装板不锈钢 D环手拧螺丝 × **1 颗**（锁紧 RS30 底盘中心）
  2. `M4 × 25mm` 杯头内六角螺丝 × **4 颗** +（可选）`M4×6×6mm` 热熔铜螺母 × **4 颗**（锁死 M2 与 M1 四角，也可直接拧入 `Ø3.8mm` 自攻盲孔）
  3. `1.0mm` 自粘植绒布胶条 1 卷（贴 M1 左右滑轨面防刮）+ `1.5~2.0mm` 硅胶防滑脚垫（必贴于 M1 底座四角底面防桌面平移打滑）+ `Ø170mm` 防尘网片 1 片
